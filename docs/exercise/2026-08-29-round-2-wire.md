## Findings

### W2-1. Withdrawn: floor doc-code divergence was a stale read
**Filed as a doc error, refuted on verification against current main.** This lane read README and degradation.md before the fix pass's doc-sync commit and saw 0.50/0.45 beside shipped defaults of 0.60/0.55. Current main documents 0.60/0.55 in both places with the superseding two-distribution measurement (28 unrelated pairs: p50 0.408, p95 0.530, max 0.547; 10 genuine matches: min 0.451, p50 0.773), and the old 0.588 figure survives only in the calibration comment, correctly, as one of the two in-band genuine matches that corroboration admits. The design answer is worth recording: the distributions overlap between 0.451 and 0.547, so no single cosine separates them; 0.60 sits above the whole noise sample and the corroboration floor (0.55, above the noise max) admits genuine in-band matches on a second leg. Kept here rather than deleted so the committed record shows the finding was filed, checked, and withdrawn.

### W2-2. CLI stream hygiene
**Severity: polish.** Two shapes, same class. `bin/aion` rebuilds the image when sources are newer and the Docker build log writes to stdout, so the first `aion proposals ls` after a source change returns Dockerfile output ahead of (and interleaved with) the command's own output; anyone piping the CLI gets build noise. And a usage error (`unknown option '--yes'`) reports on stderr with a zero-visibility failure mode when stderr is redirected: the command appears to succeed while doing nothing. Fix shape: build progress to stderr; usage errors to stdout with a nonzero exit.

### W2-3. Pre-round contradictions persist side by side as current
**Severity: known posture, worth one decision.** Content stored before the proposals machinery existed has no proposals: the whitepaper-title reversal from round 1 still serves "leading candidate" and the final title as equal `current` facts, ranked by relevance. Detection only runs at enrichment, so history never gets re-judged. Options: accept as documented cold-start posture, or run a one-time retroactive detection sweep over existing fact pairs as a maintenance operation. Belongs in the maintenance-phase planning either way.

### W2-4. Claim-level apply leaves the derived family current
**Severity: observation, working as designed.** `apply` closes exactly the claim; sibling derived nodes (entity glosses, a restatement Event) stay `current` unless `--episode` is used. The CLI hint makes the next step discoverable, which this lane rates as good ergonomics rather than a defect. Recorded because a caller reading only the pack after a bare `apply` still meets stale-flavored glosses; the parked entity-description freshness work is the real fix for those.
